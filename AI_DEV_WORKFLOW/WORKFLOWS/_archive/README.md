# Archivio Workflow completati

Workflow con stato **Completato** possono essere spostati qui per mantenere `WORKFLOWS/` leggibile.

## Regole

1. Spostare il file `WF_XX_<NOME>.md` in questa cartella **senza** rinominare.
2. Aggiornare `01_EXECUTION_ROADMAP.md` → stato «Completato (archiviato)» + link a questo path.
3. Aggiornare `03_PROJECT_STATUS.md` → sezione completati o rimuovere da attivi.
4. **Non modificare** file archiviati salvo correzioni storiche con nota in cima al file.
